# Mode D:多面试组合管理(Pipeline 视图)

> **触发**:用户说「我现在面着哪几家」「下一步该联系谁」「我的面试 pipeline」「最近哪场要准备」等。

## 执行步骤

### Step 1:扫描 sessions/ 目录

> `sessions_dir` 取自 `config.md`。先读 config 拿到路径。

```bash
ls -la "<sessions_dir>/"
```

读取每个公司子目录下的 `00-基础信息.md`,提取:
- 公司名
- 岗位
- 当前轮次
- 下一步动作(待面试 / 等待回复 / 已 Offer / 已 reject)
- 面试时间(若有)
- 优先级(用户标记的)

### Step 2:生成 Pipeline 表格

输出一份汇总表:

> 标题里的称呼取自 config.md 的 `user_name`。

```
# <user_name> 求职 Pipeline · <日期>

## 一、状态汇总

| 公司 | 岗位 | 阶段 | 下一步 | 时间 | 优先级 | 备注 |
|-|-|-|-|-|-|-|
| <公司 A> | <岗位> | R1 完成 | 等 R2 通知 | - | 🔴 高 | <一句话备注> |
| <公司 B> | <岗位> | R2 待面 | 准备项目深度题 | <日期 时间> | 🔴 高 | <备注> |
| <公司 C> | <岗位> | R1 待面 | 准备 R1 | <日期 时间> | 🟡 中 | <备注> |
| ... | | | | | | |

## 二、紧急度排序(按时间)

1. **本周内有面试**:
   - <日期>:<公司> R<X> — 准备状态:<已生成调研/需再过一遍/...>

2. **等待回复**:
   - <公司>:R<X> 后已 N 天,可考虑主动跟进

3. **跟进 / 待启动**:
   - [新投递的公司,还没收到面试通知]

## 三、本周建议动作

- [ ] <日期>:<公司> R<X> 准备一遍,重点 <题号>
- [ ] <日期>:<公司> 面试当天,提前 1 小时复习 05-话术速查.md
- [ ] <日期>:跟进 <公司> HR,礼貌询问后续安排
- [ ] 持续:每天看行业动态,补 R3 行业判断题素材

## 四、状态变更提醒

[列出超过 7 天没动静的公司,提醒主动跟进或断舍离]
```

### Step 3:状态自动判断逻辑

按以下规则给每家公司打标:

| 状态 | 判断逻辑 |
|-|-|
| 🆕 新建 | 只有 00-基础信息.md,还没调研 |
| 📋 已调研未面 | 有 01-05,但没有 06 |
| 💬 R1 完成等回复 | 有 06 但 00 显示 R1 状态 |
| 🔥 R2/3 待面 | 00 显示 R2+ 即将到来 |
| ✅ 已 Offer | 00 显示 Offer |
| ❌ 已 reject | 00 显示 reject |
| ⏸️ 停滞 | 7 天以上无更新 |

### Step 4:跟进建议

对状态 = "停滞" 的公司,主动建议:
- 距离上次面试 5-7 天:建议礼貌跟进 HR
- 距离上次面试 7-14 天:建议最后一次跟进
- 距离上次面试 14+ 天:建议放入"已无下文"清单

### Step 5:输出格式

**简洁版**(默认):直接 markdown 表格 + 本周 todo
**详细版**(用户说「详细」):每家公司展开成段落,带"应该重点关注什么"

## 持续维护机制

提醒用户:
- 每次 Mode C 完成后会自动更新 00-基础信息.md 的状态字段
- 用户也可以手动编辑 00-基础信息.md 的状态
- Skill 不主动发起跟进操作(发邮件/微信),只生成 todo
